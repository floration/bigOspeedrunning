# ℤ is Diophantine in ℚ

**Our value:** 179 variables, degree 4, 2,841 terms
**Listed record:** 257 (an explicit 179 is already public from Jose Brox)
**Status:** Claimed.

## What changed
This is only a re-encoding of Brox's 179-variable system with the same rational zero set, using invertible residual row operations, positive weights and variable rescaling. It wins the term-count tiebreak and adds no mathematics.

## How to check it
